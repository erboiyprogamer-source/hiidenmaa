# Hiidenmaa

Viikinkihenkinen 3D-selviytymispeli, joka toimii suoraan selaimessa. Kerää puuta ja kiveä,
rakenna suoja ennen yötä, takoa kuparista aseet, tutki Hautakummun luolasto ja voita Kalmanvartija.

**Pelaa:** https://erboiyprogamer-source.github.io/hiidenmaa/

Toimii parhaiten tietokoneella hiirellä ja näppäimistöllä. Voit myös ladata repon ja avata
`index.html`-tiedoston suoraan selaimessa.

## Ohjaus

| Näppäin | Toiminto |
| --- | --- |
| WASD | liiku (Shift juoksee, välilyönti hyppää) |
| Hiiri | käännä kameraa, vasen lyö tai jännittää jousen, oikea torjuu kilvellä |
| E | poimi, avaa, käytä |
| Tab | reppu ja valmistus |
| 1–8 | pikapaikat |
| B | rakennusvalikko (vasara kädessä), R kääntää, X purkaa |
| M | kartta |
| Esc | tauko ja tallennus |

## Tekniikka

three.js (r128) ja tavallinen JavaScript ilman build-vaihetta. Rakenne ja kehitysohjeet:
[`CLAUDE.md`](CLAUDE.md) ja [`docs/KEHITYSMUISTIO.md`](docs/KEHITYSMUISTIO.md).

Hiidenmaa on oma alkuperäinen teos, jonka inspiraationa on Valheim.
